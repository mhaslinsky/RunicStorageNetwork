# Постройки, радиусы и рецепты

Справочник для **Runic Storage Network 1.0**. [English version](https://github.com/rerit33/RunicStorageNetwork/wiki/Buildings-and-recipes) · [Все настройки](https://github.com/rerit33/RunicStorageNetwork/wiki/Configuration-RU).

## Назначение

| Объект | Что делает |
| --- | --- |
| Ядро сети хранилищ | Создаёт сеть, подключает ближайшие хранилища и снабжает крафт, улучшение предметов и строительство. При взаимодействии можно задать необязательное имя сети. |
| Рунное реле | Расширяет существующую сеть, подключает ближайшие хранилища и снабжает окружающую область, пока есть путь до ядра. |
| Кодекс запасов | Открывает список ресурсов с поиском и выдаёт предметы в инвентарь. Ставится в радиусе снабжения сети. Не расширяет покрытие и не принимает предметы на хранение. |
| Рунический мост | Два моста с одинаковым именем связи соединяют удалённые участки одной сети. Вокруг каждого действуют радиусы реле. Требует удалённых сетей; игроков не телепортирует. |
| Рунный кодекс | Переносимая книга — ингредиент Кодекса запасов и Кодекса строителя. Собственного радиуса действия нет. |
| Рунный кодекс строителя | Используйте книгу на ядре для привязки, затем экипируйте в слот аксессуара, общий с Мегингъёрдом. Снабжает строительство только из привязанной сети; не снабжает других игроков и не расширяет покрытие станков. |

## Радиусы по умолчанию

Расстояния указаны в метрах и измеряются между позициями объектов с учётом высоты. Это радиусы или предельная длина связи, а не диаметры.

| Связь или функция | По умолчанию | Настройка в `[Network]` |
| --- | ---: | --- |
| Ядро → хранилище | 20 м | `StorageRadius` |
| Ядро → крафт, строительство, доступ через Кодекс запасов | 20 м | `SupplyRadius` |
| Реле или мост → хранилище | 20 м | `RelayStorageRadius` |
| Реле или мост → крафт, строительство, доступ через Кодекс запасов | 20 м | `RelaySupplyRadius` |
| Обычная связь между узлами сети | 50 м | `RelayLinkRange` |
| Экипированный Кодекс строителя → ядро или подключённое реле | 50 м | `RelayLinkRange` |
| Удалённая связь между парой мостов | Без ограничения расстояния | Отдельной настройки нет |

Все пять настраиваемых радиусов допускают значения **1–100 м**. Кодекс строителя использует настройку дальности связи: отдельного параметра у него нет, напрямую к мосту он не подключается. У Кодекса запасов собственного сетевого радиуса нет. Для продолжения работы с его окном нужно оставаться в пределах **5 м**; эта дистанция взаимодействия не настраивается.

Реле можно выстраивать в цепочки: ограничение 50 м относится к каждой связи, а не ко всей сети. До ядра должен оставаться непрерывный путь. Доступ к выгруженным частям обеспечивает функция удалённых сетей.

Одно имя связи могут использовать ровно два моста. Третий отключает пару до устранения конфликта. Мосты сохраняют привязку и не объединяют независимые сети. Через удалённую связь проходят только ресурсы, разрешённые для обычных порталов настройками мира; местные ресурсы и обычные пути через реле остаются доступны. Переименование сети не сбрасывает привязку Кодекса строителя; для смены сети используйте книгу на другом ядре.

## Рецепты

Рецепты открываются по обычным правилам знакомства с ингредиентами. Все четыре постройки создаются **молотком** (категория `Crafting`), требуют ближайший **верстак**, не расходуют топливо и возвращают материалы при разборке.

| Объект | Где создаётся | Материалы на один объект |
| --- | --- | --- |
| Ядро сети хранилищ | Молоток | Камень ×30, качественная древесина ×20, цепь ×2, ядро суртлинга ×4, глаз грейдворфа ×10 |
| Рунное реле | Молоток | Камень ×10, качественная древесина ×6, железо ×2, ядро суртлинга ×1, глаз грейдворфа ×5 |
| Кодекс запасов | Молоток | Рунный кодекс ×1, качественная древесина ×10, камень ×8, железо ×2, красный джут ×2 |
| Рунический мост | Молоток | Камень ×20, древесина Иггдрасиля ×10, серебро ×6, кристалл ×10, очищенный эйтр ×5 |
| Рунный кодекс | Кузня, уровень 1 | Серебро ×4, кристалл ×2, глаз грейдворфа ×6, льняная нить ×4, обрывки кожи ×4 |
| Рунный кодекс строителя | Чёрная кузница, уровень 1 | Рунный кодекс ×1, чёрное ядро ×1, очищенный эйтр ×5, серебро ×2, кристалл ×2 |

## Связанные настройки

| Настройка | По умолчанию в 1.0 | Назначение |
| --- | --- | --- |
| `[Network] SupplyEnabled` | `true` | Снабжение ресурсами из сети. |
| `[Network] RescanIntervalSeconds` | `2` | Интервал обычной проверки структуры сети; допустимо 0,5–30 секунд. Это не таймер обновления ресурсов для каждой операции. |
| `[Content] StorageCodexEnabled` | `true` | Рецепт терминала и доступ к хранилищу. |
| `[Content] BuildersCodexEnabled` | `true` | Рецепт экипируемой книги, привязка и увеличенный радиус строительства. |
| `[Content] RunicGatewayEnabled` | `true` | Рецепт моста и его сетевые связи. |
| `[Experimental] ExperimentalUnloadedNetworks` | `true` | Удалённые хранилища и API; также требуется мостам. |

При обновлении сохранённые настройки остаются, включая прежнее `false`. Переключатели контента сохраняют уже созданные объекты при отключении. Удалённые сети обязательны только для моста; Кодекс запасов и Кодекс строителя работают и с сетью в загруженной области. Настройки сети и контента синхронизируются с сервера. Параметр удалённых сетей должен совпадать во всех установках и требует полного перезапуска после изменения. Фильтры хранилищ, настройки инструментов и диагностика описаны на странице [Настройки](https://github.com/rerit33/RunicStorageNetwork/wiki/Configuration-RU).
